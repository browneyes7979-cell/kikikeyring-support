앱에 저장하는 정보

키캡 색상·캐릭터·소리·배열, 획득한 아이템, 클릭 수, 연령 구간은 기기에 저장합니다. 추천 보상 이용 시에는 아래에 설명한 최소 정보가 별도 서버에 저장됩니다. 계정 가입, 이름, 정확한 생년월일, 위치, 카메라, 마이크, 연락처 정보는 요구하지 않습니다. 기기의 앱 데이터 삭제 또는 앱 삭제로 로컬 데이터를 지울 수 있습니다. 자동 백업을 사용하지 않습니다.

어린이와 청소년을 위한 광고 보호

키키키링은 어린이와 청소년을 주 대상으로 합니다. Google Play Families 자체 인증 대상 Google AdMob SDK를 사용하고 모든 광고 요청에 아동 대상 처리 및 전체 이용가(G) 콘텐츠 등급을 적용합니다. 개인 맞춤 광고 및 리마케팅을 사용하지 않습니다. 연령 구간은 앱 안에 저장하며 Google 동의 SDK에는 미성년자·연령 미확인 여부를 전달합니다. 연령 선택 화면을 마치고 이용자가 광고 보기를 선택할 때에만 광고를 요청합니다.

선택형 보상 광고

이용자가 캐릭터·소리 아이템을 받기 위해 선택형 보상 광고를 이용하는 경우 Google AdMob을 사용합니다. 광고 제공·부정행위 방지·진단을 위해 Google은 IP 주소에 따른 대략적인 위치, 기기 정보 및 앱 세트 식별자(App Set ID), 광고와 앱의 상호작용 및 진단 정보를 처리할 수 있습니다. 앱은 Android 광고 ID 권한을 요청하지 않으며 광고 요청은 비개인화 설정을 사용합니다. 지역에 따라 Google 동의 화면이 표시될 수 있으며 앱의 ‘광고 개인정보 설정’에서 선택을 변경할 수 있습니다. 광고를 보지 않아도 기본 키캡 놀이와 모든 색상을 사용할 수 있습니다.

친구 공유와 추천 보상

친구 보상 화면을 열거나 보상을 이용하면 Cloudflare Workers와 D1으로 운영하는 추천 서버에 연결됩니다. 서버는 무작위 설치 식별자의 해시, 무작위 추천코드, 코드 입력 관계, 공유 보상 날짜, 보상 지급·사용 내역과 선택한 보상 아이템 ID를 저장합니다. 보상 중복 지급 방지와 재연결 복구를 위해 보관합니다. 이름, 이메일, 전화번호, 연락처와 메시지 내용은 추천 서버에 전송하지 않습니다. 연령과 키캡 꾸밈 전체 구성도 전송하지 않습니다. 네트워크 제공자는 통신 과정에서 IP 주소 및 요청 진단 정보를 처리할 수 있습니다. Cloudflare 요청 로그는 최대 7일 보관되며, 보상 기록은 서비스 운영 기간에 보관합니다.

공유는 Android 공유 메뉴를 통해 이용자가 직접 대상을 고릅니다. 앱은 공유 대상 선택만 알 수 있으며 실제 메시지 전송이나 수신을 확인하지 않습니다. 앱 삭제는 기기 내 정보를 지우지만 서버 보상 기록까지 자동으로 삭제하지는 않습니다. 서버 기록 삭제를 원하면 앱에 표시된 추천코드와 함께 아래 지원 이메일로 문의해 주세요. 별도의 회원 계정 가입은 없습니다.

선택형 잠금화면 놀이와 권한

이용자가 잠금화면 놀이를 켜면, 화면 켜짐·꺼짐과 기기의 잠금 여부를 기기 안에서 감지하여 잠긴 화면 위에 키링 놀이를 엽니다. 이를 위해 다른 앱 위에 표시 권한을 이용자가 직접 허용해야 합니다. 켜진 동안 작은 키링 바로가기 버튼과 실행 알림을 표시하며, 앱·알림·놀이 화면의 끄기 버튼으로 종료할 수 있습니다. 다른 앱 화면·입력 내용·비밀번호를 읽거나 저장하지 않으며, 이 감지 정보를 서버로 보내지 않습니다. 잠금화면 놀이에는 광고가 없습니다. 밀어서 잠금 해제는 Android의 인증 화면을 호출하며, PIN·지문은 운영자나 앱이 수집하지 않습니다.
